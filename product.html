Add the styles. Start composing.

Include the stylesheets in this order. The core provides the primitives, the theme sets the palette and components add the blocks a page uses.

<link rel="stylesheet" href="css/core.css">
<link rel="stylesheet" href="css/themes/default.css">
<link rel="stylesheet" href="css/components/content.css">

Use a section for outer spacing, a grid to arrange related items, and a card when the content needs a visible boundary.

<section class="section grid grid-2">
  <article class="card stack">
    <h2>A clear heading</h2>
    <p>Content that finds its own height.</p>
  </article>
</section>

The download contains the core stylesheet only. Keep the theme and SVG assets alongside it to reproduce the examples, or use your own visual assets.

Make the shared choices your own.

Override theme variables after the core stylesheet. Change the palette or spacing without copying every component rule.

:root {
  --accent: #285d6b;
  --space-inline: 4rem;
  --radius: .8rem;
}
Can I use my own build process?

The output is ordinary HTML and CSS. Shared templates can be generated before deployment without requiring a browser runtime.

What is outside the current toolkit?

Translation routing, form processing, catalogue search and checkout are site-level integrations. Prastora provides a visual starting point, not those application features.
