A different starting point for responsive design.

Prastora grew out of a practical preference: let the content use the screen, instead of holding it in a narrow column surrounded by increasingly large margins.

A viewport-linked rem scale carries proportions across typography, spacing and components. Responsive rules still change the composition where needed, particularly for reading and navigation on smaller screens.

Scale is a design choice, not a substitute for testing. Prastora is still being refined through page examples and real-device review.
