An experimental CSS framework

Websites that keep their composition on every screen.

Most layouts stretch, squeeze and rearrange themselves until the design is somewhere else. Prastora scales the whole page instead, like a picture, so what you composed is what people see, from a phone to a television.

All templates in one place

What you get

No build step

Link the CSS files and start. Nothing to install, compile or update next spring.

Layers that keep the peace

Core, theme, components and page styles sit in cascade layers, so they stop overriding each other by accident.

JavaScript only when unavoidable

Galleries, filters, price switches and form checks run on HTML and CSS. Pages still work when scripts don’t load.

Checks included

A short script keeps the rules, and screenshot comparisons catch the changes you didn’t mean to make.
