Paragraph / ordinary wrapping

A useful layout gives each idea enough room to be understood. Typography, spacing and imagery should support the message without competing for attention. Small refinements can make a page calmer to read, especially when a paragraph ends with a single short word.

Paragraph / text-wrap: pretty

A useful layout gives each idea enough room to be understood. Typography, spacing and imagery should support the message without competing for attention. Small refinements can make a page calmer to read, especially when a paragraph ends with a single short word.

Pretty asks the browser to favour better line endings, such as avoiding a very short final line. It may make no visible difference to a particular paragraph. It involves extra layout work, so this trial is limited to one sample.
