The official pages were fetched directly after web search was cancelled. Open Props is a design-token library rather than a conventional page framework. This is a set of reference points, not a like-for-like top-ten survey.

Prastora copy follows the familiar promise → capabilities → examples → getting-started structure. It is original copy focused on proportional scaling, full-width composition, native HTML and minimal runtime overhead. Complete page examples are useful, but are not claimed to be unique to Prastora. Experimental status and integration boundaries remain explicit.
