The workflows check.yml and land.yml come from A-Rozum/plyn-tools/workflows and are replaced at every release. Every repository, private or public, lands from the agent's environment: after pushing the final [ready] commit, the agent runs `python .system/tools/plyn_land.py` (GH_TOKEN set), which validates, runs the project checks, squashes onto the default branch and posts the statuses check and land; landing spends no GitHub Actions minutes. A project adds its own checks as .github/workflows/check-<n>.yml posting the commit status check/<n>, and gives their local command in `# local: <command>` lines of that file; plyn_land runs those lines in a checkout of the branch tip and posts check/<n> itself. A project check runs on Actions only when it cannot run in the agent's environment; landing then waits for its status.
