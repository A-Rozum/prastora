The workflows check.yml and land.yml come from A-Rozum/plyn-tools/workflows and are replaced at every release. They run in public repositories. In private repositories GitHub Actions jobs are skipped so that no Actions minutes are spent: after pushing the final [ready] commit, the agent lands its branch with `python .system/tools/plyn_land.py` (GH_TOKEN set), which validates, squashes onto the default branch and posts the statuses check and land. A project adds its own checks as .github/workflows/check-<name>.yml that post the commit status check/<name>; landing waits for them. In a private repository a project check runs on Actions only when it cannot run in the agent's environment; otherwise it skips private repositories and AGENTS.md gives its local command.
