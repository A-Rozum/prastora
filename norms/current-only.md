# Current material only
ROADMAP.md holds open plans only; lab/ holds temporary notes with a question, a review date and an exit. When a task is accepted, its entry is deleted in the same commit. No logs, status reports or done lists — history is in git. A one-off check tool is deleted after the check; only tools agents run regularly are kept.
Derived from the ecosystem principle of current material (A-Rozum/system).
